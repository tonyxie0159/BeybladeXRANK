# UI 規格

手機優先，Bootstrap responsive。

## 頁面

### Login

欄位：

- Account
- Password

按鈕：

- 登入

### Home

只提供必要入口：

- 開始對戰
- 我的陀螺
- 我的戰績
- 對戰紀錄
- 帳號設定
- 待處理對戰邀請與數量

### Beyblade List

顯示：

- 名稱
- 編輯
- 新增
- 刪除

### Create Battle

流程必須分段顯示：

1. 選擇對手並送出邀請
2. 對手接受後，雙方各自選擇自己的三顆陀螺
3. 各自排列順序並提交；雙方都提交後才同時公開
4. 雙方確認，或提出每人每版至多一次的重新編輯請求
5. 裁判指定 B Side（藍）與 X Side（紅）並開始對戰

確認後鎖定。

選擇頁提供「新增我的陀螺」、「刷新陀螺」與「刷新對戰狀態」。流程頁定時輪詢並保留手動刷新按鈕。

### Battle Screen

最重要畫面。

上方：

- 玩家 A 名稱
- 玩家 A 分數
- 玩家 B 名稱
- 玩家 B 分數
- 當前 Round
- 當前雙方陀螺名稱

中央使用大按鈕：

- 轉停勝利 +1
- 擊飛勝利 +2
- 爆裂勝利 +2
- 極限勝利 +3

另有：

- A 發射失誤
- B 發射失誤
- 選手棄權
- 取消對戰（需二次確認，且整場不計戰績）

每次事件後重新顯示：

- 當前比分
- 當前陀螺 fault count
- 是否達成 >=4
- 是否可以完成 Round

達成 >=4 時顯示明確提示：

「已達勝利條件，請確認後按對戰結束」

不要自動完成。

### Round 判決修改

提供目前 Battle 的 Round 列表。

點選任一 Round：

- 顯示該局全部有效／無效事件。
- 可重新設定 BattleResult。
- 可修正整局勝負結果。
- 儲存後重新計算整場比分。

得分方式必須使用與 Battle Screen 相同的中文名稱。

### Statistics

分成：

- 我的總戰績
- 我的陀螺
- 對手戰績
- 對戰歷史

陀螺列表至少支援：

- 得分排序
- 失分排序
- 勝率排序
