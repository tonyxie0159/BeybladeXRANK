# UI 規格

手機優先，Bootstrap responsive。

## 頁面

### Login

欄位：

- Account
- Password

按鈕：

- 登入

### Home

只提供必要入口：

- 開始對戰
- 我的陀螺
- 我的戰績
- 對戰紀錄
- 帳號設定

### Beyblade List

顯示：

- 名稱
- 編輯
- 新增
- 刪除

### Create Battle

流程必須分段顯示：

1. 選擇對手
2. 選擇雙方三顆陀螺
3. 排列順序
4. 確認陣容

確認後鎖定。

### Battle Screen

最重要畫面。

上方：

- 玩家 A 名稱
- 玩家 A 分數
- 玩家 B 名稱
- 玩家 B 分數
- 當前 Round
- 當前雙方陀螺名稱

中央使用大按鈕：

- 轉停 +1
- 擊飛 +2
- 爆裂 +2
- 極限 +3

另有：

- A 發射失誤
- B 發射失誤

每次事件後重新顯示：

- 當前比分
- 當前陀螺 fault count
- 是否達成 >=4
- 是否可以完成 Round

達成 >=4 時顯示明確提示：

「已達勝利條件，請確認後按對戰結束」

不要自動完成。

### Round 判決修改

提供目前 Battle 的 Round 列表。

點選任一 Round：

- 顯示該局全部有效／無效事件。
- 可重新設定 BattleResult。
- 可修正整局勝負結果。
- 儲存後重新計算整場比分。

### Statistics

分成：

- 我的總戰績
- 我的陀螺
- 對手戰績
- 對戰歷史

陀螺列表至少支援：

- 得分排序
- 失分排序
- 勝率排序
